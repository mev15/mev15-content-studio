# 青十五 IP

## 角色定义

青十五是这套中文正文配图的固定视觉 IP。角色身份以 `assets/ip-reference/qing-shiwu-avatar.jpg` 为准，精确轮廓可对照同目录下的 SVG。

默认每张图都要出现青十五。青十五不是贴纸或角落装饰，而是正在认真参与系统运转的荒诞工作者。参考图里的水果只是头像场景道具，不是角色固定配件，除非主题需要，不要默认画出来。

## 外形

- 纯白填充、黑色手绘轮廓，头部与上半身连成一个巨大、圆润、略不规则的团块。
- 只出现上半身；下缘可以自然伸出画面、藏在桌后或被核心物件遮挡。绝不画腰部以下、腿、脚或完整站立身体。
- 两只黑色实心点眼左右不对称：画面左眼更靠外且略小，画面右眼更靠内且略大。
- 两道短斜眉左右分开，带一点专注、认真和不动声色的疑问感。
- 两条细线手臂从上半身前方或侧面伸出，手部保持极简，用来完成核心动作。
- 没有固定嘴型；不要为了表达情绪添加夸张嘴巴、牙齿或腮红。
- 轮廓保持手绘轻微抖动，不要变成规整圆形、胶囊人或实心黑色角色。

## 性格

- 很认真，但做的事有点荒诞。
- 像一个沉默、专注的系统操作员。
- 有一点笨拙和冷幽默，但不蠢、不卖萌。
- 情绪主要通过短眉、点眼视线、手臂动作和身体倾斜表达，不靠复杂表情。
- 像在白板草图里真的负责某个工作。

## 常见职责

让青十五用上半身和细手臂承担核心动作：

- 从桌后探出上半身，搬运、分拣或记录素材。
- 从机器后露出上半身，拉线、推杆、按按钮或修补断点。
- 从洞口或物件中露出上半身，伸手接住、捞取或递交内容。
- 双手拉住路径、扶住梯子、搭桥、开门、称重或盖章。
- 抱住过大的物件，或被流程中的东西压住、卡住、拖着走。
- 用一只手指向问题，另一只手维持系统运转。
- 通过身体倾斜和视线方向表达输入、处理、输出或反馈关系。

## 禁止

- 不要画出下半身、腿、脚、鞋或完整站立姿势。
- 不要把角色画成实心黑色、普通人形、雪人、豆子或带耳朵的动物。
- 不要把左右不对称的点眼和短斜眉改成对称五官。
- 不要添加复杂服装、帽子、头发、鼻子、夸张嘴巴、闪亮眼睛或腮红。
- 不要默认复制参考头像中手持的水果，也不要让水果变成固定标志。
- 不要把青十五画成过度可爱的吉祥物、表情包或儿童卡通角色。
- 不要让青十五只从角落探头观看；手臂、视线或身体必须推动核心结构。
- 不要让角色抢走结构表达，也不要把轮廓画得太商业、太圆滑、太精致。

## 判断标准

同时满足以下条件才算合格：

- 第一眼能认出参考图中的青十五：白色圆润上半身、黑色不规则轮廓、不对称点眼和短斜眉。
- 只出现上半身，没有任何腿或完整身体。
- 如果去掉青十五，图的核心隐喻不能完全成立；否则角色太装饰，要重写提示词让它成为动作主体。
