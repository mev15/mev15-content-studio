# Upstream and modifications

Upstream project: <https://github.com/op7418/guizang-social-card-skill>

This skill is a lightweight derivative of Guizang Social Card Skill and remains licensed under GNU AGPL-3.0-or-later.

Modifications in this distribution, dated 2026-08-10:

- Reduced the scope to static Xiaohongshu 3:4 carousels.
- Removed WeChat cover, Live Photo, web image sourcing, style selection, and manual review branches.
- Replaced free-form HTML composition with a deterministic storyboard JSON renderer.
- Fixed one Qing Shiwu Swiss brand system and added configurable identity metadata.
- Made validation and unified workspace preview registration automatic.
- Added Xiaohongshu caption generation as part of the storyboard contract.
- Added a Twitter-style author shell while keeping semantic carousel layouts.
- Tightened copy compression to preserve source wording and added user-directed source-image range filtering.
